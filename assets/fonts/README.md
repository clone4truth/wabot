# Bubble fonts

Roboto Regular and Medium are bundled so the chat layout has consistent font
metrics on the host and in Docker. Other scripts and colour emoji use the
installed Noto fallback fonts.

Source: https://github.com/googlefonts/roboto-2/tree/main/src/hinted

These unmodified font files are distributed under the included Apache 2.0
license in `LICENSE-Roboto.txt`.
